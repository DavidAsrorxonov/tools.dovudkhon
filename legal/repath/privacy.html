Repath Privacy Policy

Last updated: September 12, 2026

Repath is a Chrome extension that redirects URLs based on rules defined locally by the user.

Single Purpose

Repath has one purpose: to redirect browser requests from one URL to another according to rules configured by the user.

Data Handled by Repath

Repath may process the following data only to provide its redirect features:

  • User-defined redirect rules, including source and destination URL patterns.
  • Request URLs evaluated against redirect rules to determine whether a redirect applies.
  • Local extension settings, such as enabled or disabled redirect rules.

Local Processing

Repath evaluates and applies redirect rules locally in the browser using Chrome's declarativeNetRequest API. The extension does not send browsing activity, visited URLs, or redirect rules to the developer or to third parties.

Storage

Repath uses Chrome local extension storage to save redirect rules and settings on the user's device. This data remains on the user's device and is not transmitted elsewhere.

Repath does not store browsing history or visited URLs beyond what is needed to apply redirect rules in real time.

Data Sharing

Repath does not sell, rent, share, or transfer user data to third parties. Repath does not use user data for advertising, analytics, profiling, or personalized advertising.

Remote Code

Repath does not execute remotely hosted code. All extension code is packaged with the installed extension.

Human Access

The developer does not have access to redirect rules, browsing activity, or any data stored locally by Repath on the user's device.

Limited Use

Repath uses information handled by the extension only to provide and improve its single purpose: local URL redirection. Repath complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to This Policy

This privacy policy may be updated if Repath changes how it handles data. Any changes will be reflected on this page.

Contact

For privacy questions about Repath, contact the developer through the support channel listed on the Chrome Web Store listing.
