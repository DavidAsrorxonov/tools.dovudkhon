JSON Lens Privacy Policy

Last updated: September 12, 2026

JSON Lens is a Chrome extension for inspecting JSON documents and JSON network responses locally in Chrome.

Single Purpose

JSON Lens has one purpose: to help developers inspect JSON documents and JSON network responses locally in Chrome.

Data Handled by JSON Lens

JSON Lens may process the following data only to provide its JSON inspection features:

  • Direct JSON document content opened in the browser.
  • JSON network response bodies visible in the DevTools panel.
  • Request URLs and response metadata shown in the DevTools panel.
  • Local viewer preferences, such as expansion depth and preview length.

Local Processing

JSON Lens processes inspected JSON locally in the browser. The extension does not send inspected JSON, browsing activity, request data, response content, or viewer preferences to the developer or to third parties.

Storage

JSON Lens uses Chrome local extension storage to save viewer preferences on the user's device. These preferences include settings such as default expansion depth, string preview length, rendered row limit, and virtualization threshold.

JSON Lens does not store inspected JSON response content permanently.

Data Sharing

JSON Lens does not sell, rent, share, or transfer user data to third parties. JSON Lens does not use user data for advertising, analytics, profiling, or personalized advertising.

Remote Code

JSON Lens does not execute remotely hosted code. All extension code is packaged with the installed extension.

Human Access

The developer does not have access to inspected JSON content, browsing activity, request data, response content, or locally stored viewer preferences.

Limited Use

JSON Lens uses information handled by the extension only to provide and improve its single purpose: local JSON inspection. JSON Lens complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to This Policy

This privacy policy may be updated if JSON Lens changes how it handles data. Any changes will be reflected on this page.

Contact

For privacy questions about JSON Lens, contact the developer through the support channel listed on the Chrome Web Store listing.
